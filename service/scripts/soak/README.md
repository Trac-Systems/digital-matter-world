# Accounting and measurement helpers

The old service-funded stack driver and financial workload were removed with the
service inscription wallet. They must not be used as evidence for pay-first.
The retained helpers test exact paid Trac retry identities, bounded measurements,
process ownership and supply conservation. Accounting burns mint units on `mc`.
Run `node --test service/test/soak*.test.mjs`. See
[the current rehearsal guide](../../../deploy/REHEARSAL.md) for player-paid checks.
